# 易 — 人生決策輔助器

> 在困惑或卡住時，陪你看清楚：該停一下、勇敢一次，或現在也很好。

**線上體驗：** [biology-c.github.io/I-Ching-reading](https://biology-c.github.io/I-Ching-reading/)

## 最新更新

- **一個選擇就夠了**：結果後只留下「此刻想怎麼做」的一層選項，點一下自動收進卦跡；文字紀錄收合為選填，不再像完成日記作業。
- **結果直達我的卦跡**：結果頁可直接打開七日回顧，不必先繞回首頁；七日紀錄也改為陪伴式回顧，不再用完成度催促使用者。
- **方向頁完整可見**：桌面在 100% 縮放即可看清主要選項；手機保留雙欄並避開瀏覽器工具列，較矮畫面也能從標題開始完整捲動。
- **卦象說完，換你選**：看完提示後可用帶點個性的標籤留下此刻真正的選擇；卦象建議與個人回應分開保存。
- **最近 7 日回顧**：以每日第一卦累積七日軌跡，整理使用者最常做的選擇與隔日結果；沒有連續使用也不會歸零。
- **幽默也是答案**：加入「那當然！」「相信你自己」以及偶爾有點無厘頭的補充，讓答案保留喘息與會心一笑的空間。
- **深邃明暗雙主題**：可隨時切換原有深色與暖霧明亮主題；選擇會保留在目前裝置，粒子也會隨主題從對比色盤隨機換色。
- **三種決策陪伴**：所有方向都會整理為「停一下、勇敢一次、現在也很好」，提供參考而不替使用者做決定。
- **512 則卦象解答**：六十四卦各 8 則，包含 4 則原創格言、2 則原創預言故事與 2 則《易經》名著名言。
- **解答藏書**：每天第一卦收錄一則；同一卦的 8 則收齊前不會重複收藏，並保留未來擴充到 4,096 則的資料結構。
- **今日一卦與卦跡**：保存當時卡住的問題、卦象、提示、心得與收藏，資料只留在目前裝置。
- **隔日回聲**：隔天回到自己當時的選擇，記下已完成、做到一部分、改變主意、尚未行動或已經不需要。
- **六十四卦圖鑑**：每天只有第一卦可以解鎖，避免為收集而反覆重抽。
- **有效分析與回饋**：完整記錄使用流程；設定正式服務後可送往 GA4 與回饋端點，未設定端點時會明確開啟郵件寄送。

## 功能

- **三種起卦方式**
  - 一念成卦 — 快速得到一組卦象
  - 數字起卦 — 輸入六組三位數，以數理推卦
  - 擲幣問天 — 模擬三枚銅錢，六次定爻

- **三段式解卦**
  - 現狀（本卦卦辭）
  - 轉折（動爻爻辭）
  - 趨向（變卦結語）

- **五大問卦方向** — 是／否、感情、學業、工作、財運
- **生活小事快速判斷** — 「是／否」入口已置頂，可更快得到「是 / 否 / 先等等」的簡答參考
- **人生決策陪伴** — 以「停一下 / 勇敢一次 / 現在也很好」協助整理舉棋不定的狀態
- **卦象解答之書** — 依本卦從 512 則內容中呈現格言、預言故事或名著名言
- **個人決策回應** — 只用一層標籤留下自己的選擇；想留一句話時再展開選填
- **七日重整回顧** — 以每日第一卦整理最近七日的個人選擇與隔日結果，不以連續打卡為目標
- **決策卦跡** — 保存問題、卦象、決策提示、個人回應、心得、收藏與隔日回聲
- **六十四卦圖鑑** — 每日第一卦才計入解鎖，留下長期使用的陪伴痕跡
- **解答藏書** — 以六十四卦分冊保存已遇見的內容，顯示每卦 `0 / 8` 與全庫 `0 / 512` 進度

- **社交分享與互動**
  - **分享專屬連結** — 複製帶有 hash 參數的網址，對方開啟即還原同一卦象
  - **生成結果圖片** — 將卦象與決策陪伴提示轉為分享卡片
  - **收藏與回饋** — 收藏會寫入個人卦跡；回饋會送往設定端點或開啟郵件寄出

## 技術

純前端、無框架，以 HTML、CSS 與 JavaScript 建立。卦跡使用 `localStorage` 保存在使用者裝置。

### 分析與回饋設定

在 `js/config.js` 設定服務資訊：

```js
window.YI_CONFIG = Object.freeze({
  gaMeasurementId: 'G-你的 GA4 ID',
  feedbackEndpoint: 'https://你的回饋端點',
  feedbackEmail: '你的備援信箱'
});
```

- `gaMeasurementId`：設定後才會載入 GA4；留空時不會載入假的追蹤碼。
- `feedbackEndpoint`：可填入接受 JSON `POST` 的 Formspree 或自有 API。
- `feedbackEmail`：沒有回饋端點時，網站會開啟使用者的郵件程式並要求確認寄出。
- 本機分析摘要可在瀏覽器 console 輸入 `Analytics.getReport()` 查看。

### 隱私

使用者填寫的問題、心得與隔日回聲只保存在目前裝置，不會送到 GA4。分享網址也不包含問題文字。
